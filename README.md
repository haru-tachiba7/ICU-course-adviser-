# 履修台帳 — ICU 履修計画アプリ

ICU(国際基督教大学)の4年間の履修を、メジャーの卒業要件に照らして確認するための、
ブラウザだけで動く履修計画ツールです。バックエンド・サーバーは不要で、`index.html`
を開くだけで動作します。あなた自身の履修データ(何を追加したか、状態、区分)は
ブラウザの `localStorage` に保存され、他の場所には送信されません。

## ファイル構成

```
index.html   … アプリ本体(画面・ロジック)
data.js      … 科目カタログ・卒業要件のデータ(自動生成)
cap_rules.js … 単位の上限・下限ルール
majors.js    … 全30メジャーの一覧・ELAストリーム別の必要単位データ
scripts/
  parse_search_results.py … ICU公式サイトの保存HTMLから data.js を再生成するスクリプト
  build_single_file.py    … index.html+data.js+cap_rules.js+majors.js を1ファイルに結合するスクリプト(Claudeアーティファクト公開用)
```

## データの更新方法(学期の変わり目など)

ICU公式サイトには外部から直接取得できるAPIがないため、以下の手順でデータを更新します。

1. https://campus.icu.ac.jp/public/ehandbook/SearchCourseAndSyllabus.aspx を開く
2. 表示件数を「ALL」に切り替える(必要なら年度・学期を指定)
3. ページを保存する(ブラウザの「名前を付けて保存」→「ウェブページ、完全」)
4. 以下を実行する

   ```bash
   pip install beautifulsoup4 lxml
   python3 scripts/parse_search_results.py path/to/saved.html
   ```

5. `data.js` が更新されるので、コミットしてページを公開し直す

## 卒業要件区分について

「ディプロマ・ポリシー及び卒業要件」(2026年度入学者向け)に基づき、以下のルールで自動分類しています。

- 基礎科目 = 各メジャーの科目のうち、全学共通科目を除いた**100番台**の科目
- 専攻科目 = 選択中のメジャーの科目のうち**200番台以上**の科目
- それ以外(選択中のメジャー以外の200番台以上の科目)は選択科目として扱う
- 語学(ELA/JLP)・一般教育(GE系)・保健体育(HPE)・卒業研究(STH)は科目番号の接頭辞から判定

この判定はメジャーを問わず共通のロジック(`courseCategory`関数、index.html内)で行っており、
ヘッダーでメジャーを切り替えると基礎科目・専攻科目・選択科目の割り当ても連動して変わります。

この分類は科目番号だけから機械的に判定したものです。メジャー未決定の1〜2年次に履修した専門科目は、
公式には「メジャー決定後に正式な区分へ振り分け直される」仮の扱いである点に注意してください。

## 単位の上限・下限ルール(cap_rules.js)

`cap_rules.js` に、卒業要件の付帯ルールを保持しています(現時点で3件)。

- 一般教育科目の必修超過分は、最大9単位まで選択科目に算入できる
- 保健体育科目の必修超過分は、最大2単位まで選択科目に算入できる
- 基礎科目18単位のうち、選択したメジャーの基礎科目を最低6単位含める必要がある(アプリ内で選択中メジャーの科目の内訳を表示・警告)

## メジャーの選択について

ヘッダーの「メジャー」で、情報科学を含む全30メジャーから選べます。メジャーを切り替えると、
基礎科目・専攻科目・選択科目の判定がそのメジャーの科目番号(接頭辞)を基準に再計算されます。
科目データ自体はメジャーごとに作り直す必要がなく、1つのdata.jsを全メジャー共通で使えます。

科目一覧の「すべてのメジャー(科目群)」フィルタで、特定メジャーの科目だけに絞り込むこともできます
(現在選んでいるメジャーとは独立して、閲覧用に別のメジャーの科目群を見ることができます)。

## ELAストリームについて

ヘッダーの「語学トラック」でELAのStream 1〜4を選ぶと、公式資料(ディプロマ・ポリシー及び卒業要件)
の数値に基づいて、英語(ELA)と選択科目の必要単位数が自動で設定されます(単一メジャーの場合の値)。

| Stream | 英語(ELA) | 選択科目 |
|---|---|---|
| Stream 1 | 6単位 | 56単位 |
| Stream 2 | 10単位 | 52単位 |
| Stream 3 | 22単位 | 40単位 |
| Stream 4 | 25単位 | 37単位 |

「(手動設定)」のままにしておけば、必要単位の数字を直接クリックして個別に設定できます
(免除や日本語教育プログラム(JLP)、ダブルメジャー/メジャー・マイナーなど、単一メジャーのStream以外のケース向け)。

英語(ELA)・日本語(JLP)の必要単位は、配属されたストリームによって変わるため、
アプリの「必要単位」の数字をクリックすると直接編集できます。

## GitHub Pagesで公開する場合

このリポジトリのルートに `index.html` があるため、GitHub Pages の設定で
「Deploy from a branch」→ ブランチ `main` / フォルダ `/(root)` を選ぶだけで公開できます。
