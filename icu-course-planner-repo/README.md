# 履修台帳 — ICU 履修計画アプリ

ICU(国際基督教大学)の4年間の履修を、メジャーの卒業要件に照らして確認するための、
ブラウザだけで動く履修計画ツールです。バックエンド・サーバーは不要で、`index.html`
を開くだけで動作します。あなた自身の履修データ(何を追加したか、状態、区分)は
ブラウザの `localStorage` に保存され、他の場所には送信されません。

## ファイル構成

```
index.html   … アプリ本体(画面・ロジック)
data.js      … 科目カタログ・卒業要件のデータ(自動生成)
scripts/
  parse_search_results.py … ICU公式サイトの保存HTMLから data.js を再生成するスクリプト
```

## データの更新方法(学期の変わり目など)

ICU公式サイトには外部から直接取得できるAPIがないため、以下の手順でデータを更新します。

1. https://campus.icu.ac.jp/public/ehandbook/SearchCourseAndSyllabus.aspx を開く
2. 表示件数を「ALL」に切り替える(必要なら年度・学期を指定)
3. ページを保存する(ブラウザの「名前を付けて保存」→「ウェブページ、完全」)
4. 以下を実行する

   ```bash
   pip install beautifulsoup4 lxml
   python3 scripts/parse_search_results.py path/to/saved.html
   ```

5. `data.js` が更新されるので、コミットしてページを公開し直す

## 卒業要件区分について

現時点で自動的に区分を割り当てているのは、科目番号の接頭辞から機械的に判定できるもの
(ELA・JLP・GE系・HPE・STH)だけです。それ以外(専攻科目・基礎科目・選択科目になりうる
科目)は、情報科学メジャーの公式卒業要件との照合がまだ済んでいないため、意図的に
「未分類」のままにしてあります。アプリ内で科目を履修リストに追加する際に、手動で
区分を指定してください。

英語(ELA)・日本語(JLP)の必要単位は、配属されたストリームによって変わるため、
アプリの「必要単位」の数字をクリックすると直接編集できます。

## GitHub Pagesで公開する場合

このリポジトリのルートに `index.html` があるため、GitHub Pages の設定で
「Deploy from a branch」→ ブランチ `main` / フォルダ `/(root)` を選ぶだけで公開できます。
